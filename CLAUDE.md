This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Arcade Vault: an online games platform where players compete for the highest scores (README is in Spanish). The project follows Spec Driven Design using the `/spec` and `/spec-impl` workflow, with skills from `Klerith/fernando-skills` (installed via `npx skills@latest add Klerith/fernando-skills`). Currently only the Create Next App scaffold exists — no games, scoring, or backend yet.

## Commands

- `npm run dev` — dev server (http://localhost:3000)
- `npm run build` / `npm start` — production build / serve
- `npm run lint` — ESLint (flat config, `eslint.config.mjs`)
- No test runner is configured.

## Next.js version warning

This is Next.js 16.4 / React 19.3, with breaking changes from what you may know. `AGENTS.md` requires reading the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next.js code, and heeding deprecation notices. `AGENTS.md` is regenerated by `next dev`.

## Architecture notes

- App Router only (`app/`). Path alias `@/*` maps to the repo root.
- `next.config.ts` enables non-default features: `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. `cacheComponents` changes caching/dynamic-rendering semantics, so check the docs before fetching data or using dynamic APIs in components.
- Tailwind CSS v4 is wired through Turbopack rules (`@tailwindcss/turbopack` loader for `*.css` in `next.config.ts`) rather than PostCSS; there is no postcss config. Theme tokens live in `app/globals.css` (`@theme inline`).
- `app/layout.tsx` uses the globally typed `LayoutProps<"/">` helper (no import) and loads Geist fonts via `next/font/google`.
